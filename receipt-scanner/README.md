# Receipt Scanner

AI-powered receipt scanning workflow built with n8n.

This workflow automatically:
- receives receipt images from Telegram
- extracts text using OCR
- structures receipt data using AI
- uploads receipts to Google Drive
- saves expense data into Google Sheets
- sends confirmation messages back to Telegram

## Features

- OCR receipt scanning
- AI information extraction
- Telegram bot integration
- Google Sheets logging
- Google Drive storage
- Automated expense tracking

## Requirements

This workflow may require external APIs, credentials, accounts, or third-party services depending on your setup.

## Import Workflow

1. Download `workflow.json`
2. Open n8n
3. Click `Import from File`
4. Select the workflow file
