# n8n Workflows

A collection of ready-to-use n8n workflows for AI automations, productivity, integrations, and business use cases.
This repository contains multiple workflow categories, from simple automations to advanced AI-powered systems.

## What's Inside

### AI & Automation
Workflows that use AI to do smart things automatically.
- AI agents
- Expense tracking with AI
- Document scanning and OCR
- AI email assistants
- Auto data extraction

### Messaging & Notifications
Send and receive messages across different platforms.
- Telegram
- Discord
- Slack
- Email
- WhatsApp

### Productivity
Make everyday tasks faster and more organised.
- Google Sheets automations
- Calendar workflows
- Task management
- CRM automations

### Integrations
Connect n8n with popular tools and services.
- OpenAI
- Supabase
- Notion
- Airtable
- APIs and webhooks
- Databases

### Business & Operations
Workflows for running and growing a business.
- Lead generation
- Invoice processing
- Customer support automations
- Analytics workflows

## How to Use a Workflow

1. Download the `.json` file for the workflow you want
2. Open your n8n editor
3. Click **Import from File**
4. Select the downloaded `.json` file
5. Set up any credentials or API keys the workflow needs

## Requirements

Each workflow may need different things to run — such as API keys, third-party accounts, or credentials. Check the notes inside each workflow before running it.
